About the Arcade

Classic Games, Modern Arcade Shell

ChillGaming is a browser-based retro arcade built with HTML5, CSS3, vanilla JavaScript, Canvas API, and LocalStorage. It brings multiple classic game styles into one consistent dashboard so players can switch games without leaving the arcade experience.

The platform includes Tetris, Snake, Tic-Tac-Toe, PacMan, Flappy Bird, and Space Invaders. Each game has its own rules and controls, while sharing the same HUD, score saving, difficulty setting, pause/restart flow, and mini leaderboard.

Tetris focuses on falling tetrominoes, rotation, line clearing, level progression, and next-piece planning. Snake uses grid movement, food spawning, collision checks, and increasing speed. Tic-Tac-Toe supports local player-versus-player and player-versus-AI rounds.

The PacMan-inspired game adds maze navigation, pellets, ghosts, lives, score, and win/game-over conditions. Flappy Bird uses jump physics and pipe obstacles. Space Invaders adds ship movement, bullets, enemy waves, collisions, lives, and scoring.

Scores, nickname, settings, sound preferences, and difficulty choices are saved locally in the browser. The current app now uses the unified dashboard as the single place to launch and play every game.
