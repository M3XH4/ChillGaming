## 🚀 About

**ChillGaming** is a browser-based retro arcade platform built with **HTML5, CSS3, and JavaScript** that combines classic arcade gameplay with modern web technologies.

Inspired by the golden age of arcade machines, ChillGaming provides a unified gaming experience featuring multiple iconic games, responsive controls, score tracking, and a visually immersive neon-retro interface.

Whether you're on desktop, tablet, or mobile, ChillGaming delivers smooth and engaging gameplay directly in your browser.
